# awr2944_driver

Community ROS 2 driver for TI AWR2944P DDM point clouds over UART and Ethernet.
This package is not an official Texas Instruments ROS driver.

See the repository [usage guide](https://github.com/SangwooJung98/awr2944p_ros2_driver)
for installation, board connections, firmware selection, configuration and RViz.
The included replay data is synthetic. The license is Apache-2.0.
