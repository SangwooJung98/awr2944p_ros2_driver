# 검증 기록과 한계

2026-10-21 기준입니다. 이 문서는 실제 보드 관찰과 공개 저장소의 자동 테스트를 구분합니다.

## 실제 보드

- AWR2944PEVM / AWR2944P에서 UART DDM과 SDK 4.7.2.1 DDM_ENET 포인트 수신 및 RViz 표시를 확인했습니다.
- AWR2944P 안테나 배열·DDM 순서로 수정한 Ethernet cfg에서 340프레임, 약 10.0000 Hz, 18,219포인트를 수신한 구간이 있습니다. 해당 구간의 파싱 오류·발행 큐 누락·빈 포인트 프레임은 0이었습니다.
- 이후 USB-LAN 분리와 USB 오류로 측정이 중단됐습니다. 어댑터 교체 후에도 오류가 관찰됐으므로 장시간 연속 동작은 검증 완료 상태가 아닙니다.
- 이전 안테나 설정에서 수집한 약 314초의 TCP 기록에서는 완성 프레임 3,140개, TCP 순번 공백 0, 빈 프레임 0이었습니다. 그 중 ROS 600프레임은 원본과 변환 결과가 일치했습니다. 이 결과는 전송·파싱 검증이며 안테나 모델의 정확도를 검증한 결과가 아닙니다.
- 과거 USB 수신 검증에는 이전 안테나 cfg가 사용됐습니다. 공개 USB cfg는 AWR2944P 배열로 수정했으나 이 수정본의 UART 실측은 수행하지 않았습니다.

개별 보드의 거리·위상 보정, 장착 자세/TF, 기준 표적을 이용한 각도·거리 오차, 고온·장시간 안정성은 검증하지 않았습니다. 서로 다른 시점의 포인트 수를 USB/Ethernet 전송 방식의 성능 차이로 해석하지 않습니다.

## 공개 자동 테스트

자동 테스트는 합성 UART 데이터, CSV 기대값, PTY CLI 에뮬레이터, localhost TCP와 실제 ROS 2 메시지·서비스를 사용합니다. 보드가 연결되지 않아도 실행됩니다.

공개본은 Ubuntu 24.04 / ROS 2 Jazzy에서 빌드한 후 **43개 테스트 통과, 실패·오류·건너뜀 0개**를 확인했습니다.

검증 항목은 패킷 분할·결합, 손상·비정상 길이·NaN·0포인트, Ethernet 프레이밍, ROS 축·필드·타임스탬프, 시작·정지·재시작 순서, 무수신 정지, 반복 SIGINT 종료, AWR2944P 안테나 설정입니다. GitHub Actions는 Ubuntu 24.04 / ROS 2 Jazzy에서 동일 테스트를 실행하도록 구성했습니다.

합성 데이터는 `tools/generate_sample.py`에서 재현할 수 있습니다. 자동 테스트의 통과는 RF 하드웨어 성능이나 물리적 측정 정확도를 입증하지 않습니다.
